    How it works

    • mainnet-js v3 — BCH wallet, transaction building, Electrum reads (balances, UTXOs, history). Same code path for testnet and mainnet; only the network flips.
    • WizardConnect — QR handshake over an encrypted Nostr relay; the wallet shares its xpubs, BlazePay derives your receive and change addresses (first 20 of each) and scans them all for funds, then asks the wallet to sign (sign_transaction_request). Keys never leave the wallet.
    • No backend, no custody — a static page. Payment links are just URLs (#/pay?to=…&amt=…&memo=…). The memo rides on-chain as OP_RETURN.
    • CashTokens — the banner address is the token-aware address of this project; EMBER2026 donations fund Community Choice voting.
